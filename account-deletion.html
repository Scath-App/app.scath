Account Deletion Process

How we handle data removal and account deletion requests

Scath provides a straightforward and secure way for users to delete their accounts and all associated data directly from within the application. This process ensures compliance with data protection standards and gives users full control over their information.

1. The User Interface (UI)

The account deletion option is located in the Verification / Personal Details screen.

  • At the bottom of this screen, there is a "Delete Account" button outlined in red.
  • When the user taps this button, a Confirmation Modal appears. It warns the user: "Are you sure you want to delete your account? All your data will be permanently removed."
  • The modal prevents accidental deletions by requiring the user to explicitly press "Delete" to confirm.

2. The Local State & Hooks

Once the user confirms the action in the modal:

  • The application handles the request securely using our internal state management.
  • The request is initiated safely, ensuring all local data states are prepared for deletion.

3. The API Service

The application communicates with our secure servers to process the deletion:

  • An authenticated DELETE HTTP request is sent to our backend services.
  • This request automatically includes your secure authentication token to verify your identity before any data is removed.
  • Our backend then permanently removes your account records and associated personal data from our active databases.

4. Post-Deletion Cleanup

If the backend successfully processes the deletion:

  • The application automatically clears all cached user data stored locally on your device.
  • You will be logged out of the application.
  • The UI hides the confirmation modal and displays a success notification confirming that your account has been deleted.
